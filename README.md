# TaskTracker

## Descrição Funcional
O TaskTracker é um sistema de gestão de tarefas desenvolvido para centralizar e simplificar a organização diária. Permite o registo, visualização e conclusão de atividades, operando através de uma interface de linha de comandos.

## Tecnologias Utilizadas
* Python 3
* Git e GitHub

## Como Instalar e Executar
1. Clone este repositório para a sua máquina local.
2. Abra o terminal e navegue até à pasta raiz do projeto.
3. Execute o comando: `python src/main.py`
